# Biswas IT Firm — Modern Business Website

A modern, responsive, and performance-focused business website for **Biswas IT Firm**.
The website presents the company's services, portfolio, testimonials, FAQs, and contact information through a clean and user-friendly interface.

## Features

* Fully responsive design for desktop, tablet, and mobile
* Modern business-focused UI
* Light and dark theme support
* Responsive mobile navigation
* Active navigation based on the visible section
* Service details displayed through an accessible modal
* Portfolio category filtering
* Testimonial slider with autoplay controls
* FAQ accordion
* FAQ search by question text
* Search-term highlighting
* Accessible live announcements
* Smooth scrolling for internal navigation
* Reduced-motion support
* Keyboard-friendly interactions
* Semantic HTML structure
* Performance-conscious JavaScript
* Optimized DOM manipulation
* Lazy/non-critical interaction handling where applicable

## Technologies Used

* **HTML5** — Semantic and accessible page structure
* **CSS3** — Responsive layout, animations, themes, and visual styling
* **JavaScript (ES6+)** — Interactive functionality and DOM manipulation
* **Font Awesome** — Service and interface icons

## Responsive Design

The website is designed to work across different screen sizes:

* Desktop
* Tablet
* Mobile

The layout, navigation, service cards, portfolio, testimonials, FAQ, and contact areas adapt to smaller screens.

## Performance Testing

The website can be tested using:

* Google Lighthouse
* Chrome DevTools
* PageSpeed Insights

Important areas to monitor include:

* Performance
* Accessibility
* Best Practices
* SEO
* Main-thread work
* JavaScript execution
* Unused JavaScript
* Image delivery
* Largest Contentful Paint (LCP)

## 🎯 Project Goal

The goal of this project was to create a more modern and professional web presence for Biswas IT while keeping the experience:

**Fast · Responsive · Accessible · User-friendly · Maintainable**
